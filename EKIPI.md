# EKIPI

## Projekti

**FixIt: gjej dhe rezervo shërbime lokale.** Aplikacion mobil (Expo / React Native) ku njerëzit në Kosovë gjejnë profesionistë vendorë (berber, frizer, elektricist, hidraulik, mekanik, pastrim) dhe rezervojnë termin direkt nga telefoni, pa telefonata dhe pa mesazhe në Instagram.
